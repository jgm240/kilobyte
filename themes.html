Kilobyte's own

Add yours

In Kilobyte: Settings › Colour theme › Theme editor. Make a theme with New, then Upload: it shows a QR code and a link to this page with your theme in it. Open it on a phone or computer and submit it. Gallery in the theme editor gets the themes from here; a downloaded .kbtheme file goes in with Import.
