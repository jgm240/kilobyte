Transition

Keep your system. Add Kilobyte next to it, and switch with one word: on Linux, macOS and Windows.

Install on Linux

On Debian, Ubuntu or Raspberry Pi OS, in a terminal:

cd /tmp && wget -q https://jgm240.github.io/kilobyte/kilobyte-transition.deb && sudo apt install ./kilobyte-transition.deb

The package brings its own APT repository, so later versions come with sudo apt upgrade. The programs it recommends (video, games, the offline encyclopedia) take a few hundred MB; for the Program Manager alone, add --no-install-recommends after install.

How it works on Linux

Kilobyte runs on a text console of its own (the sixth, Ctrl+Alt+F6), where you are logged in by yourself. Your desktop keeps running on its own console; kb switches between the two, and each stays exactly as you left it. kb close goes back to the desktop, and kb autolaunch on starts the computer straight into Kilobyte. In Kilobyte, Exit › "Back to the desktop" does the same as kb close. kb asks for your password: it is for users who may use sudo.

Kilobyte leaves the computer's own settings alone: the network, users, fonts, printers and updates stay with your desktop's tools, and Kilobyte's Settings show only its own things.

Removing it: sudo apt remove kilobyte-transition puts the computer back as it was and keeps the repository, so apt install kilobyte-transition brings Kilobyte back; sudo apt purge kilobyte-transition removes the repository too.

The repository by hand

The same, without the one-line package:

sudo curl -fsSLo /etc/apt/keyrings/kilobyte-archive-keyring.gpg https://jgm240.github.io/kilobyte/apt/kilobyte-archive-keyring.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/kilobyte.sources https://jgm240.github.io/kilobyte/apt/kilobyte.sources
sudo apt update && sudo apt install kilobyte-transition

The packages are signed with the key in kilobyte-archive-keyring.asc.

Install on macOS

With Homebrew, in Terminal:

brew trust jgm240/kilobyte
brew install --cask jgm240/kilobyte/kilobyte

That puts Kilobyte in Applications. Open it: the first time, macOS asks you to allow it (System Settings › Privacy & Security › "Open Anyway", once) and whether it may use Terminal. Then it sets itself up, which downloads about 1 GB once and takes a few minutes.

Only the kb command, without the app: brew install jgm240/kilobyte/kilobyte-transition, then kb open.

How it works on macOS

Kilobyte runs in a small Debian machine made with Lima, using the Mac's own virtualisation, and shows in Terminal. kb open (or the app) starts it; Exit in Kilobyte closes the window, and kb close also stops the machine and frees its memory. kb autolaunch on opens Kilobyte when you log in, kb update gets the newest Kilobyte, and your Mac's home folder can be read from inside it.

Removing it: kb remove deletes Kilobyte's machine, then brew uninstall --cask kilobyte.

Install on Windows

In a terminal (Windows Terminal or PowerShell):

winget install Kilobyte.Transition

Then type kb open. The first time it turns on WSL if it is off (Windows asks for permission and then wants one restart; type kb open again afterwards), downloads Kilobyte (about 280 MB), checks it and sets it up.

Until the package is listed in WinGet, take the zip from the Kilobyte for Windows release, unpack it and run kb open from that folder.

How it works on Windows

Kilobyte runs as a Linux system of its own in WSL, the part of Windows that runs Linux, and shows in Windows Terminal with Kilobyte's colours and pixel font. Exit in Kilobyte closes it; kb close stops it. kb autolaunch on opens Kilobyte when you sign in. Your Windows drives are in /mnt (C: is /mnt/c), and Kilobyte Update in Settings keeps Kilobyte new.

Removing it: kb remove deletes Kilobyte's system, then winget uninstall Kilobyte.Transition.

The kb command

  • kb opengo to Kilobyte
  • kb closeleave Kilobyte
  • kb autolaunch onKilobyte first, at every start
  • kb autolaunch offnot any more
  • kb removeremove Kilobyte
