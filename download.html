What will Kilobyte run on?

Not sure whether a PC is 64-bit? Windows says it in Settings > System > About ("System type"); on Linux, uname -m says x86_64. Most PCs since 2007 are. A Kindle: KilobytEink. Keeping Debian, Ubuntu or Raspberry Pi OS: Transition.

PCs

USB stick: write the -usb.img file (or the ISO) to the stick with balenaEtcher, Raspberry Pi Imager ("Use custom"), or on Linux and macOS:

sudo dd if=kilobyte-1.5-amd64-usb.img of=/dev/sdX bs=4M status=progress

CD: burn the CD version's ISO as an image (not as a file). Virtual machine: start the ISO in QEMU, VirtualBox or UTM. Kilobyte runs from the stick or CD; "Install Kilobyte to disk" in the Program Manager puts it on the hard disk (the CD version can also keep Windows 98 next to it).

Tested on: Medion Akoya E6240 and Sony VAIO PCG-71811M; a MacBook Pro (Late 2008) is being tested. See them.

Raspberry Pi

Write the .img.xz file to a memory card with Raspberry Pi Imager ("Use custom") or balenaEtcher; no need to unpack it. The first start asks for keyboard, time zone, name and password, and makes the system fill the card.

KilobytEink (Kindle)

For a jailbroken Kindle with the Universal Hotfix (scriptlets) and kterm. Copy the folders documents and kilobyteink from the ZIP to the Kindle's main folder over USB; "KilobytEink" then shows up in the Library. The ZIP's README.txt has the details, and Update_kilobyteink_boot_install.bin makes the Kindle start straight into it.

Already have Debian?
