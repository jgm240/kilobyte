                         KILOBYTE  -  QUICK HELP
                         ═══════════════════════

 Kilobyte is a desktop that is not really one. There is no mouse pointer
 to chase and no windows to arrange: the Program Manager starts a program,
 the program fills the screen, and when you close it you are back here.


 FINDING THINGS
 ──────────────
   Ctrl+Space     KBFind: type a few letters and it finds programs, settings,
                  files (by name, and words inside notes, index cards and
                  text documents), the agenda and the help; Enter opens it.
                  Ctrl+Space works in Kilobyte Desktop, in programs started
                  from Kilobyte and in the Terminal; KBFind is also in the
                  Program Manager.


 MOVING AROUND
 ─────────────
   ↑ ↓            move the highlight
   First letter   jump to an item (press again for the next one)
   Enter          run / open / OK
   Tab            move between the list and the buttons
   Esc            back / cancel
   Space          tick an option in a list with ( ) or [ ] boxes
   Ctrl+C         in a program: close it and come back here
                  in a menu: go back
                  in the Program Manager: shut down (it asks first)
                  In the Terminal Ctrl+C stops a command as usual.

 The bottom line of the screen explains the highlighted item.


 THE PROGRAMS
 ────────────
   Editor         mcedit. F9 opens the menu bar, F2 saves, F10 quits.
                  Shift+arrows select, Ctrl+Ins copies, Shift+Ins pastes.
                  Ctrl+C closes it too, asking to save changes first.

   Spreadsheet    sc-im. Move with the arrow keys. Type = to enter a number
                  or formula, e.g.  =A1+A2  or  =@sum(A1:A9)
                  <  or  >  enter left/right aligned text, \ centred text.
                  :w saves, :q quits, :help shows the manual.

   Email          Alpine. The first start asks for your address and sets
                  up the account (Settings > Email account changes it).
                  I inbox, C write, L folders, Q quit; Ctrl+X sends.
                  Gmail, iCloud and Yahoo need an "app password".

   Web browser    ELinks, with CSS and JavaScript. Esc opens the menu bar,
                  g types an address, arrow keys move between links,
                  Enter follows one, ← goes back, q quits. Big web apps
                  (web mail, video sites) are too much for it: use the
                  Email and Online videos programs instead.

   File manager   mc (Midnight Commander). Tab switches panel, F3 views,
                  F4 edits, F5 copies, F6 moves, F7 makes a folder,
                  F8 deletes, F9 opens menus, F10 quits.

   Terminal       A fullscreen command line. Type exit to come back.

   Media
     Video Player   Plays videos and music from ~/Videos and ~/Music or a
                    web address. "Picture" chooses how video is shown:
                      Extreme / Fine / Medium blocks - the screen switches to
                        a tiny font (1x2, 2x4 or 4x8 pixels per character) and
                        the film is drawn with coloured characters
                      Text blocks - the same in the normal font
                      Real picture - the video itself, straight on screen
                    Space pause, left/right seek, 9/0 volume, q stops.
     Music Player   Songs from ~/Music with dancing bars. Enter plays, Space
                    pauses, N and P next and previous, + and - volume,
                    S shuffle, R repeat, W saves the list as a playlist,
                    L opens one.
     Online videos  Search YouTube or paste a link, then watch, save the
                    video (MP4) or save only the sound (MP3). If YouTube
                    stops working, choose "Update the downloader".
     Disc Player    DVD films, audio CDs and data discs. DVD menus are not
                    shown: pick a title; the main film is marked.
     Sound volume   alsamixer. Arrows change, M mutes, Esc closes.

   Settings       Wi-Fi, colour theme, wallpaper, font size, keyboard layout,
                  date and time zone, installing programs, password, task
                  manager. Swap: on a computer with little memory, switch
                  on compressed memory (it also works on the live system);
                  an installed Kilobyte can have a swap file on the disk too.
                  Kilobyte Update can undo the last update; an installed PC
                  also has "undo the last update" in its boot menu.
                  Defaults chooses the programs that open for each job: the
                  text editor (Kilobyte's, nano, vi, Vim, Micro, Emacs), the
                  web browser, file manager, email, spreadsheet and music
                  player. One that is not installed yet gets installed.


 THE DESKTOP (KILOBYTE WINDOWS)
 ──────────────────────────────
   Every program runs in a window of its own; the Program Manager stays.
     ■ Kilobyte (top line) or F12           the Programs menu: every program,
                                            the windows, copy and paste,
                                            volume, lock, log out, shut down
     icons on the desktop                   double-click opens; the right
                                            mouse button has more
     drag the title bar                     move a window: an outline shows
                                            where it goes, let go to put it
     drag the lower right corner            resize it
     double-click the title, or [▲]         maximise / restore
     [▼]                                    minimise (the bottom line brings
                                            it back)
     [X]                                    close
     Alt+Tab, or click the bottom line      switch windows
   Your files on the desktop: whatever is in the folder Desktop of your home
   folder has an icon. In the file manager, F2 > "Put on the desktop".
   Settings > Desktop icons chooses the programs that have one.

   Copy and paste: drag the mouse over text and it is copied (hold Shift
   in programs that use the mouse themselves, such as the file manager).
   The middle mouse button or F11 pastes it into the window in front.
   The Programs menu can also copy all the text of a window.

   The top line shows the network, the volume (click it for a slider),
   the battery and the clock; notes appear in the lower right corner when
   a download is done, a USB stick is plugged in or the battery runs low.
   Weather and news sit on the desktop. Settings > Wallpaper changes the
   desktop: a pattern, your own characters, colours, or a picture.

   Videos in the block modes take the whole screen while they play; the
   Text picture mode plays inside the window, and so does the real picture
   on a computer's own screen (it is drawn where the window is, and waits
   while anything is over the window).
   Settings > Login and startup switches windows off (one program at a time,
   fullscreen). Settings > Mouse pointer makes the pointer any character(s),
   in any colours and sizes: 1 is the characters themselves, 2 to 5 an arrow
   that many rows tall (kbutils settings chg pointer "<-", pointer-size 3);
   near the edges of the screen the arrow turns round.


 FILES
 ─────
   File manager   Enter opens a file with the right program: documents in the
                  editor, tables in the spreadsheet, pictures in blocks, music
                  in the Music Player, PDF files as text. F3 on a picture shows
                  it. F2 has "Open with", "Move to the trash", "Put on the
                  desktop" and "Print".
   Trash          Accessories > Trash puts things back or deletes them for good.
   Network drives Internet > Network drives connects shared folders of Windows
                  PCs and NAS boxes, and of any computer with SSH; they appear
                  as folders in ~/Network.


 SEVERAL PEOPLE
 ──────────────
   Settings > Users adds users; everybody has their own files and desktop.
   Switch user (Programs menu, or Settings > Users) lets somebody else log
   in on another console while your programs keep running; Ctrl+Alt+F1 to
   F6 go back and forth. Lock the screen (Programs menu, Accessories) hides
   everything until your password is typed; Settings > Screen saver can do
   that after the screen saver too.


 OTHER COMPUTERS
 ───────────────
   Remote Kilobyte  Internet > Remote Kilobyte uses another Kilobyte computer
                    in a window. On that computer switch on Settings > Remote
                    login first.
   Company desktops Internet > Company desktops opens the desktops and programs
                    of a company or school. Citrix's program is not part of
                    Kilobyte: download its Debian package from citrix.com and
                    choose the file there; it then opens on the graphics screen.


 THE STORE
 ─────────
   Accessories > Store installs more text-mode programs with a keypress:
   editors, system monitors, web browsers, chat, games, DOSBox. They show up
   under "More programs", and so do programs installed with APT (sudo apt
   install, or Settings > Add or remove programs) that have a menu entry.
   Graphical ones open in X (see below).


 GRAPHICAL PROGRAMS (OPEN PROGRAM IN X)
 ──────────────────────────────────────
   More programs > Open program in X runs graphical programs - Qt, GTK or
   any other X program, such as GIMP or VLC - in a Kilobyte window. They
   run in an X server that draws into memory; on a computer's own screen
   the window shows their real pixels, elsewhere (SSH) coloured blocks. The
   mouse and the keys go to the program. F9 has the menu: real pixels or
   blocks, zoom (the whole X screen, or one to one, moving along when the
   mouse is at an edge), keys that cannot be typed (Alt+F4, Ctrl+Alt+Del)
   and closing. It needs a few helpers: kbutils dl xwindows.


 EVERY DAY
 ─────────
   Today          Accessories > Today: the date, the weather, the Agenda's
                  appointments and to-dos, headlines and unread news feeds
                  on one screen. Options: show it when Kilobyte starts, the
                  town for the weather.
   Notes          Accessories > Notes: quick notes, newest first. The first
                  line is the title; a word with # in front (#shopping) is a
                  tag, and Tags lists the notes of each. Search finds any
                  word. They are text files in Documents/Notes.
   News feeds     Internet > News feeds: news sites, blogs and YouTube
                  channels in one list. Add takes a site's address (the
                  feed is found by itself) or a channel's (youtube.com/@NAME).
                  Inside: Enter opens, q goes back, o opens the page,
                  n next unread, r reloads, ? all keys, Q leaves.
                  Videos open in the Online videos program.
   Dictionary     Accessories > Dictionary: English words with WordNet, also
                  without the Internet; translates words and sentences into
                  and from many languages (on-line, by MyMemory).
   Encyclopedia   Accessories > Encyclopedia: download a Wikipedia once (from
                  130 MB for the most-read articles in short to 50 GB for
                  all of English), then read it without the Internet. Search
                  looks up an article; in the browser q comes back. A .zim
                  file copied into ~/Wikipedia works too.
   Reading videos Online videos > a video > Read it: what is said, as text with
                  the times, from the video's subtitles or YouTube's own
                  captions. Save keeps it in Documents/Transcripts.
   Sync           Accessories > Sync: keeps Documents the same on your
                  computers. Over the network, the other one needs Settings
                  > Remote login; or sync with a USB stick and carry it over.
                  Changes and deletions go both ways; if a file changed on
                  both, the newer one wins.


 ACCESSIBILITY
 ─────────────
   Screen reader  Settings > Accessibility switches on speech: what is chosen
                  in the menus and what programs write is read aloud. In the
                  boot menu of the ISO, S starts Kilobyte with speech (B also
                  with a braille display); on a Raspberry Pi, add
                  kilobyte.speech=1 to cmdline.txt on its memory card.
                  Number pad (Num Lock off): 7 8 9 line above / this / below,
                  4 5 6 words, 1 2 3 letters; Insert+F1 the reader's own help.
                  The CD version has no room for it: kbutils dl accessibility
                  downloads it.
   Braille        Settings > Accessibility > Braille display, then plug in
                  the display (USB).
   Large letters  Settings > Accessibility > Large letters (also Settings >
                  Console font), and High contrast for black and white.


 BACKUPS
 ───────
   Accessories > Backup keeps encrypted backups of your documents, pictures,
   music and settings on a USB stick, a server (over SSH) or a network drive.
   Automatic backups happen every day or week in the background; a USB stick
   gets them when it is plugged in. "Bring back files" picks a day and a
   file (or Find by its name), and puts it next to the old one, in
   Documents/Restored, or in its place. Only the changes are copied each
   time; a backup of each of the last 7 days, 5 weeks and 12 months is kept.
   Write the backup password down: on another computer it is the only way in.


 OTHER KILOBYTES NEARBY
 ──────────────────────
   Messenger      Internet > Messenger: everyone on this network who has
                  Messenger open shows up. Type and Enter sends, ↑ ↓ choose
                  a person or Everyone, F2 sends a file (they are asked
                  first; files go to Documents/Received), F3 your name.
                  No account and no server: it only works on the same
                  network, while Messenger is open.
   Host a BBS     Internet > Host a BBS makes this computer a bulletin board
                  that friends dial into with the BBS Dialer (or any telnet
                  BBS program): hostbbs from rBBS, with chat rooms, boards,
                  mail, files, games, multiplayer, polls, news and more.
                  Settings is hostbbs's own setup. Log in to it as the sysop
                  (Call) for Sysop tools; there, or at the main menu, the op
                  commands: op restart, op update (the newest hostbbs from
                  rBBS on GitHub), op help. Host a BBS has Update and Restart
                  too, and the Log: what callers did in public (never mail,
                  private messages or pages to the sysop).
                  Kids mode (Settings > K): callers say their age, features
                  go by it, rooms and boards can be for some ages, adults and
                  under-18s can't write privately, rude words are hidden from
                  the young. Parent mode: parents make their children's
                  accounts (Family, E) and approve who else may write to them.
                  Every folder in /srv/kilobyte-bbs/files is a file area.
                  Friends elsewhere need your router to forward the port.


 YOUR OWN COLOUR THEME
 ─────────────────────
   Settings > Colour theme > Theme editor makes a theme from any other: the
   desk, windows, menus, buttons and fields, each in its colours, and on the
   console even the exact colours themselves. The editor's own screens show
   the changes at once. Export saves the theme as a .kbtheme file to give
   away; Import adds one.
   Upload shows a QR code and a link to the theme gallery on Kilobyte's
   website: open it on a phone or computer to submit your theme. Gallery
   gets the themes people made.


 PARENTAL CONTROLS
 ─────────────────
   kbutils dl parentalctl installs them; then Settings > Parental controls
   (for a parent, an administrator): for each child's account, minutes per
   day (school days and weekends), the hours the computer may be used, the
   programs turned off, and the Internet always, never or only in computer
   time. Children see the time left in the top line and are warned before
   it ends; extra time can be given for today, and a report shows the last
   7 days.


 KBUTILS (THE COMMAND LINE)
 ──────────────────────────
   In the Terminal, kbutils does what Settings does:
     kbutils settings list              every setting, and what it is
     kbutils settings chg theme mustard change one (vals NAME: its values)
     kbutils settings wifi disp         show one
     kbutils settings chg wifi connect NETWORK
     kbutils dl list                    extras (the screen reader, backups,
     kbutils dl accessibility           the typing tutor...): download one
     kbutils del typing                 remove one; kbutils dl brings it back


 MORE PROGRAMS
 ─────────────
   Internet       Internet Time Machine: web sites as they were, years ago
                  (the Internet Archive's Wayback Machine): famous old sites,
                  any site in any year, or a surprise; links lead on in that
                  year.
                  Chat (IRC rooms), BBS Dialer (bulletin boards with modem
                  sounds; files they send arrive in ~/Downloads), Online videos.
   Media          Camera: Look shows the camera's picture in the Video
                  Player's picture modes (blocks, text, or the real picture);
                  S or Enter takes a photo (into Pictures/Camera), M mirrors.
                  Scan reads QR codes and bar codes: web addresses open,
                  Wi-Fi codes connect (it asks first), contacts become index
                  cards; Scan a picture reads them from photos and screenshots.
                  Podcasts: Find searches the podcasts of the world, or Add
                  takes a podcast's address. Episodes download into
                  Music/Podcasts and play in the Music Player; Newest shows
                  what is new in all of them.
   Accessories    Paint: arrows move, Space draws, , and . change colour,
                  P L B X C O F E K choose the tool, S saves, U undoes.
                  Print, USB sticks, Backup, Screen saver and more.
                  ASCII Art Generator: a heading in big letters (figlet's
                  fonts), a subheading, and art: big letters, a picture made
                  of characters, or your own text, in a border of any
                  characters. Saves to Documents/ASCII Art; prints portrait
                  or landscape, as big as the page allows.
                  Typing tutor: learn to type with ten fingers, in many
                  languages; Esc leaves a lesson.
                  Fan control: the temperatures and fans, and how the fans
                  run: A automatic (the computer's own way), Q quiet, N
                  normal, C cool (faster as it gets warmer), F full speed,
                  or 1-9 a fixed 10% to 90%. Above 85 °C every fan runs at
                  full speed. It sets PC fan chips, Intel Macs' fans and the
                  Raspberry Pi 5's fan; on a ThinkPad T allows it (after a
                  restart), on other Pis G sets up a fan on a GPIO pin.
                  (kbutils settings chg fan quiet)
   Games          Mines, Solitaire, Reversi, Moon Buggy, Snake and others.
                  Each shows its keys on the bottom line.
                  Chess: pick a piece with Space and put it down with Space,
                  or type the move (e2e4); U takes back, 1/2/3 strength.
                  Sudoku: arrows and numbers, ? for help.
                  Text adventures: stories you play by typing what to do
                  (look, take lamp, go north); free ones download with Enter.
   Settings       Also: Wi-Fi hotspot, Bluetooth, printers, screen saver,
                  weather and news tiles, sounds, automatic login.


 WHERE THINGS ARE
 ────────────────
   Your documents are kept in ~/Documents (notes in Documents/Notes,
   stories and their saved games in Documents/Stories), index cards in ~/Cardfile,
   videos in ~/Videos, music in ~/Music, the desktop's files in ~/Desktop
   and network drives in ~/Network.


 DOS PROGRAMS
 ────────────
   Accessories > DOS programs runs DOS programs and games in DOSBox, an
   emulated DOS PC with VGA graphics and Sound Blaster sound. The folder DOS
   in your home folder is drive C:. Opening a DOS .exe, .com or .bat file
   starts it there. Ctrl+F9 ends DOSBox.

 WINDOWS PROGRAMS
 ────────────────
   Accessories > Windows programs runs .exe and .msi files with Wine.
   With windows, graphical programs open in a window of their own, in a
   Windows desktop (as with Open program in X; F9 has its menu). Without
   windows they open full screen and you come back here when they close;
   Ctrl+Alt+Backspace leaves at once. Installed
   programs live in ~/.wine (drive C:). On a Raspberry Pi, Wine for PCs runs
   through box64 or box86, which translate PC code for the ARM processor:
   it works, slowly, and not with every program.


 DVDs
 ────
   Most films on DVD are encrypted. Debian does not include the library
   needed to read them (libdvdcss) because it is not legal everywhere. Where
   it is allowed, install it in the Terminal:
     sudo apt install libdvd-pkg && sudo dpkg-reconfigure libdvd-pkg
   (first add "contrib" to the lines in /etc/apt/sources.list).
   Home-made DVDs, audio CDs and data discs work without it.


 THE MOUSE
 ─────────
   On the text console the mouse shows as a block. The web browser and
   the Program Manager's text programs that support it react to clicks.


 INSTALLING
 ──────────
   When Kilobyte runs from a USB stick or CD, "Install Kilobyte to disk"
   in the Program Manager copies it onto the computer's hard disk.
   Everything on that disk is erased.


 CONSOLES
 ────────
   Ctrl+Alt+F2 ... F6 switch to other text consoles; Ctrl+Alt+F1 comes
   back. Log in there and type kilobyte to start another Program Manager.
