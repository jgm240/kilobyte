Try it

The Try page runs the real Kilobyte in a virtual PC inside the web page. That needs a graphical web browser with WebAssembly (Firefox, Chrome, Safari, Edge): open https://jgm240.github.io/kilobyte/try.html in one.

In a text browser you are, in a way, trying it already: this is what web pages look like in Kilobyte's own web browser.

To run Kilobyte for real, download it, or add it to your Debian, Ubuntu or Raspberry Pi OS with one line.
