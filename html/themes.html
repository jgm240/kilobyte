Theme Gallery

Colour themes for Kilobyte, made in its theme editor (Settings > Colour theme > Theme editor). A downloaded .kbtheme file goes in with Import there.

From people

In Kilobyte: Settings > Colour theme > Theme editor > Gallery lists them and installs one. The graphical version of this page shows them.

Add yours

In the theme editor: New makes a theme, Upload shows a QR code and a link to the gallery page with your theme in it. Open it on a phone or computer with a graphical browser and choose Submit to the gallery (it needs a GitHub account). Once it is approved, everyone can get it.
