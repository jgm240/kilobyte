Transition

Keep your system. Add Kilobyte next to it, and switch with one word: on Linux, macOS and Windows.

Jump to: Linux | macOS | Windows

Linux

Install

On Debian, Ubuntu or Raspberry Pi OS, in a terminal:

cd /tmp && wget -q https://jgm240.github.io/kilobyte/kilobyte-transition.deb && sudo apt install ./kilobyte-transition.deb

The package brings its own APT repository, so later versions come with "sudo apt upgrade". The programs it recommends (video, games, the offline encyclopedia) take a few hundred MB; for the Program Manager alone, add --no-install-recommends after "install".

Use

kb opengo to Kilobyte
kb closego back to the desktop
kb autolaunch onstart the computer into Kilobyte
kb autolaunch offstart into the desktop again

In Kilobyte, Exit > "Back to the desktop" does the same as kb close. kb asks for your password: it is for users who may use sudo.

How it works

Kilobyte runs on a text console of its own (the sixth, Ctrl+Alt+F6), where you are logged in by yourself. Your desktop keeps running on its own console; kb switches between the two, and each stays exactly as you left it.

Kilobyte leaves the computer's own settings alone: the network, users, fonts, printers and updates stay with your desktop's tools.

Removing it: "sudo apt remove kilobyte-transition" puts the computer back as it was and keeps the repository; "sudo apt purge kilobyte-transition" removes the repository too.

The repository by hand

sudo curl -fsSLo /etc/apt/keyrings/kilobyte-archive-keyring.gpg https://jgm240.github.io/kilobyte/apt/kilobyte-archive-keyring.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/kilobyte.sources https://jgm240.github.io/kilobyte/apt/kilobyte.sources
sudo apt update && sudo apt install kilobyte-transition

macOS

With Homebrew, in Terminal:

brew trust jgm240/kilobyte
brew install --cask jgm240/kilobyte/kilobyte

That puts Kilobyte in Applications. The first time you open it, macOS asks you to allow it (System Settings > Privacy & Security > "Open Anyway", once) and whether it may use Terminal; then it sets itself up (about 1 GB, once). Only the kb command, without the app: "brew install jgm240/kilobyte/kilobyte-transition", then "kb open".

Kilobyte runs in a small Debian machine made with Lima (the Mac's own virtualisation) and shows in Terminal. kb close also stops the machine; kb autolaunch on opens Kilobyte when you log in; kb update gets the newest Kilobyte; kb remove deletes the machine.

Windows

In a terminal:

winget install Kilobyte.Transition

Then "kb open". The first time it turns on WSL if it is off (Windows asks, then one restart), downloads Kilobyte (about 280 MB) and sets it up. Until the package is listed in WinGet, take the zip from the Kilobyte for Windows release, unpack it and run "kb open" there.

Kilobyte runs as a Linux system of its own in WSL, in Windows Terminal with its colours and pixel font. kb close stops it; kb autolaunch on opens it when you sign in; kb remove deletes it. Windows drives are in /mnt (C: is /mnt/c).
