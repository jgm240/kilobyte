Which file?

64-bit PC (x64; most PCs since 2007, Intel Macs)...-amd64-usb.img for a USB stick, or ...-amd64.iso
32-bit PC (i386)...-i386-usb.img or ...-i386.iso; a PC that only starts from CDs: ...-i386-cd.iso
Raspberry Pi 2 or newer...-raspberrypi-arm64.img.xz (Pi 3, 4, 400, 5, 500, Zero 2 W); Pi 2: ...-raspberrypi-armhf.img.xz
Raspberry Pi 1...-raspberrypi-armel.img.xz
Raspberry Pi Zero, Zero W...-raspberrypi-armel.img.xz
Kindle (jailbroken)kilobyteink-....zip

Not sure whether a PC is 64-bit? Windows says it in Settings > System > About ("System type"); on Linux, "uname -m" says x86_64.

The files

All files, with their .sha256 checksums and the source package lists: the release page on GitHub.

PCs

USB stick: write the -usb.img file (or the ISO) to the stick with balenaEtcher, Raspberry Pi Imager ("Use custom"), or on Linux and macOS:

sudo dd if=kilobyte-1.5-amd64-usb.img of=/dev/sdX bs=4M status=progress

CD: burn the CD version's ISO as an image (not as a file). Virtual machine: start the ISO in QEMU, VirtualBox or UTM. Kilobyte runs from the stick or CD; "Install Kilobyte to disk" in the Program Manager puts it on the hard disk (the CD version can also keep Windows 98 next to it).

Raspberry Pi

Write the .img.xz file to a memory card with Raspberry Pi Imager ("Use custom") or balenaEtcher; no need to unpack it. The first start asks for keyboard, time zone, name and password, and makes the system fill the card.

KilobytEink (Kindle)

For a jailbroken Kindle with the Universal Hotfix (scriptlets) and kterm. Copy the folders documents and kilobyteink from the ZIP to the Kindle's main folder over USB; "KilobytEink" then shows up in the Library. The ZIP's README.txt has the details.

Already have Debian?

Debian, Ubuntu or Raspberry Pi OS keep their desktop and get Kilobyte next to it: one line.
