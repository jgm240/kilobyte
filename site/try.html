The real Kilobyte, in a virtual PC that runs in this page. Nothing is installed.

Kilobyte 1.5 (CD version, 32-bit)

Starting downloads about 40 MB; the rest of the system loads as it is used.

Good to know

SpeedThe PC is emulated in JavaScript and WebAssembly (v86): slower than a real one, a bit like the 1990s PCs the CD version is made for. Programs open after a moment the first time, while their part of the system downloads.
KeysArrow keys and first letters choose, Enter runs, Esc goes back. Ctrl+C closes a program. Some keys (Ctrl+W, F11) belong to the browser.
InternetThe virtual PC has none: web, email, feeds and videos need a real Kilobyte.
Your filesEverything stays in this page and is gone when you leave or reload it.

The virtual PC is v86 (BSD licence) with SeaBIOS and the VGA BIOS (LGPL). Kilobyte is free software under the GNU GPL, version 3 or later. Source code
