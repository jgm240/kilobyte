■ Kilobyte APT repository

kilobyte-transition 1.5-5 adds Kilobyte, the text-mode desktop, to a normal Debian, Ubuntu or Raspberry Pi OS, next to its own desktop.

Install

One line in a terminal:

cd /tmp && wget -q https://jgm240.github.io/kilobyte/kilobyte-transition.deb && sudo apt install ./kilobyte-transition.deb

The package sets up this repository too, so updates come with sudo apt upgrade. Already have the repository? Then sudo apt install kilobyte-transition is enough.

Use

kb open             go to Kilobyte
kb close            go back to the desktop
kb autolaunch on    start the computer into Kilobyte
kb autolaunch off   start the computer into the desktop again

Kilobyte is free software (GNU GPL 3 or later): github.com/jgm240/kilobyte. The packages are signed with the key in kilobyte-archive-keyring.asc.
